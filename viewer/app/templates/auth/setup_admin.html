Configuración inicial

Esta instalación todavía no tiene ningún administrador. Crea aquí el primero y después inicia sesión con él.

Esta pantalla se cierra para siempre en cuanto se cree. No volverá a estar disponible, ni siquiera si más adelante se elimina o se desactiva ese administrador.

¿El formulario falla con un error 403 al enviarlo sobre http:// (sin cifrar)? Es Safari: a diferencia de Chrome, Firefox o Edge, no acepta la cookie de seguridad en localhost o 127.0.0.1 sin HTTPS. Usa otro navegador, o sirve esta instalación por HTTPS.
